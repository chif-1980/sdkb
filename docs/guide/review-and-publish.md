# 审核与发布

审核的主要对象是知识单元，不是细碎的内容块。内容块用于在原文中定位和引用，知识单元才是操作人员确认、更新和发布的业务内容。

## 局部审核

材料只更新一部分时，在右侧审核信息中处理当前知识单元：

1. 选择需要核对的知识单元。
2. 查看原文版式中的定位内容。
3. 核对跨文档证据和版本差异。
4. 选择处理结果。
5. 切换到下一知识单元继续处理。

已处理单元会保留结果，未处理单元仍留在“待我处理”，不会因为提交部分结果而消失。

## 整篇批量审核

整篇材料内容一致、风险可控且无需逐项判断时，可以使用批量操作：

- **整篇批量审核**：将所有待处理知识单元纳入知识库。
- **批量不纳入**：将所有待处理知识单元标记为不进入知识库。
- **批量退回**：将所有待处理知识单元退回飞书修改。

批量操作只作用于当前材料中尚未处理的知识单元，不覆盖已经逐项确认的结果。

## 处理结果

### 纳入知识库

内容有效、来源可靠且需要提供给知识助手使用时选择此项。任务完成后，系统会发布为正式知识。

### 不纳入知识库

内容无需进入知识库、与已有正式知识重复或不属于当前知识范围时选择此项。该结果表示已经完成判断，不是审核失败。

### 退回飞书修改

内容存在事实错误、表述不完整、版本不明确或版式解析问题，需要来源维护人员修改时选择此项。

“问题标签”仅在退回飞书修改时使用，用于说明修改方向；审核意见可选填。

## 如何核对证据

审核工作区提供三类信息：

- **当前正文**：当前材料中的原始内容和版式位置。
- **跨文档证据**：其他材料或正式知识中可能重叠的内容。
- **处理记录**：该材料和知识单元之前发生过的审核、发布与退回动作。

版式对比时，两侧可以独立翻页。证据位于不同页时，无需强制同步页码，以高亮文字和来源定位是否对应为准。

## 多格式版式还原

| 文件类型 | 核对方式 |
| --- | --- |
| PPT | 按页还原版式，同页内容块可点选定位 |
| Word | 按页面和段落还原，保留标题、表格和图片位置 |
| Excel | 按工作表和可视区域展示，支持缩放与定位 |
| PDF | 按原始页展示并叠加文字定位 |
| 图片 | 显示压缩预览，并将 OCR 文字映射到原图位置 |

大图片和复杂页面会使用适合审核的预览分辨率，原始文件仍作为最终来源保留。

## 提交后的去向

- 仍有未处理知识单元：任务继续留在“待我处理”。
- 全部选择不纳入：任务进入“已完成”，正式知识中不会新增内容。
- 全部完成且至少一项纳入：发布成功后可在“正式知识”查看。
- 选择退回：任务等待飞书来源更新后重新扫描。

提交后暂时看不到正式知识时，不要重复操作，先检查发布状态和失败信息。
