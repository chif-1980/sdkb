# 知识助手

知识助手面向普通用户提供企业知识问答。它只检索已经发布的正式知识，不会使用待审核、已退回或不纳入的内容。

## 开始提问

1. 使用组织账号登录知识助手。
2. 在输入区直接描述要解决的问题。
3. 根据需要选择简洁或详细回答模式。
4. 提交后核对回答下方的引用来源。

提问时尽量说明产品、业务场景、时间范围或目标对象。例如，“智能外呼系统有哪些部署要求”比“部署要求是什么”更容易得到准确答案。

## 回答模式

### 简洁模式

适合快速查结论、参数或步骤。回答会压缩背景说明，优先给出直接结果。

### 详细模式

适合方案比较、制度解读和复杂操作。回答会补充依据、条件、例外情况和完整步骤。

回答模式只影响表达详略，不改变可检索的知识范围。

## 查看引用

引用用于确认回答来自哪一份正式知识。展开引用后可以查看材料名称、相关内容和定位信息。

出现以下情况时，应优先相信来源原文并反馈给知识管理员：

- 回答与引用内容不一致
- 引用版本明显过期
- 不同来源之间互相冲突
- 问题涉及合同、价格或对外承诺等高风险内容

## 为什么没有回答

常见原因包括：

- 相关材料尚未完成审核和发布
- 当前账号没有对应知识权限
- 提问过于宽泛，未命中具体知识
- 正式知识正在更新或重新索引

可以换用更具体的关键词重试；仍无结果时，将问题和期望来源反馈给知识管理员。

## 知识更新何时生效

知识单元发布成功后才会进入知识助手。来源材料发生变化但尚未完成审核时，知识助手继续使用上一版有效知识，避免把未经确认的新内容直接提供给用户。
