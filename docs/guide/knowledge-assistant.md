# 企业知识助手使用手册

面向企业员工，介绍普通问答、查资料、做方案、核对来源、上传附件、管理会话和反馈问题。知识管理员维护资料时，请阅读[善达知枢使用手册](./zhishu-manual)。

**适用版本：企业知识助手 [v0.3.6](https://github.com/chif-1980/sdAssit/releases/tag/v0.3.6)；核对日期：2026 年 9 月 17 日。** 截图均来自该版本实际对话页，使用虚构演示资料和预设接口数据，展示操作位置与结果形式，不代表生产环境的检索或方案生成结果。点击截图可打开原图放大查看。

## 1. 功能架构与知识来源

[![企业知识助手 v0.3.6 浅色功能架构：普通问答、查资料、做方案，以及知识依据与反馈闭环](/images/manuals/assistant-architecture-v036-light.svg)](/images/manuals/assistant-architecture-v036-light.svg)

[下载架构图 SVG](/images/manuals/assistant-architecture-v036-light.svg) · [下载高清 PNG](/images/manuals/assistant-architecture-v036-light@2x.png)

助手的企业知识证据来自善达知枢中已审核发布、当前有效且你有权访问的正式知识。它不会因为检索不到答案，就改用待审核或不纳入的资料。会话附件可作为你此次提问的上下文，**不会自动发布到企业知识库**。

三条功能路径分别是：**普通问答获得有引用的回答，`@查资料` 查找现成文件，`@做方案` 根据需求生成可复核、保存和确认的草稿**。发现知识问题后可反馈给管理员，经复核和审核发布更新可用知识。

## 2. 登录并开始使用

1. 打开管理员提供的企业知识助手地址，确认进入的是“企业知识助手”登录页。
2. 按页面启用的方式登录；使用飞书时，扫码并在手机完成确认。二维码过期后刷新。
3. 登录成功后进入对话页。左侧管理会话，中间显示问答，下方是问题输入区。
4. 输入一个具体问题并发送；需要指定技能时，在问题中输入 `@` 选择技能。

**验收：** 页面显示你的登录身份，问题出现在当前会话，随后出现回答或明确的状态提示。

若提示没有权限，联系管理员核对账号及知识库授权。登录成功不等于有权查看所有资料；多人使用同一台电脑时，使用结束后退出账号。

## 3. 提问与技能调用

[![v0.3.6 对话首页，展示查资料、做方案技能入口和输入区](/images/manuals/assistant-chat-v036.png)](/images/manuals/assistant-chat-v036.png)

### 3.1 怎样问更容易得到有用答案

问题中尽量包含**对象、场景、范围和需要的输出**。

| 不够明确的提问 | 建议提问 |
| --- | --- |
| 怎么部署？ | 某产品的私有化部署需要准备哪些资源？请列出部署前检查步骤。 |
| 有什么区别？ | 请对比产品 A 与产品 B 在部署方式上的差异，并分别列出依据。 |
| 这个能用吗？ | 这份方案适用于哪个产品版本？有哪些需要业务确认的条件？ |

同一主题可在当前会话继续追问，例如“第二步需要哪个角色操作？”或“请按检查清单整理”。需要切换任务类型时，可输入 `@查资料` 或 `@做方案`；切换到无关主题时新建会话，避免上下文混淆。

### 3.2 选择问答还是技能

| 你要完成的事 | 使用方式 | 主要结果 |
| --- | --- | --- |
| 理解一个问题，例如“部署前要准备什么？” | 直接输入问题 | 带来源的文字回答 |
| 找到一份现成文件，例如产品说明、手册或解决方案 | `@查资料` | 相关资料卡片，可查看摘要、打开原文、下载 |
| 根据需求起草新方案或汇报提纲 | `@做方案` | 条件确认、方案草稿、依据与风险提示 |

新对话首页可点击“查资料”或“做方案 / 汇报”；也可以在输入框键入 `@`，选择技能后继续填写要求，再点击发送。自然提问也可触发技能；希望明确指定任务时，使用 `@` 最直接。

[![输入 @ 后选择查资料或做方案技能](/images/manuals/assistant-skills-v036.png)](/images/manuals/assistant-skills-v036.png)

“分析会议”仍为计划中的能力，看到入口不代表已经可用。技能不会扩大你的知识权限。

### 3.3 查资料：找到现成文件

**适合：** 找产品说明、宣传手册、白皮书、部署指南或已有解决方案。如果目的是根据新需求起草方案，使用下一节的“做方案”。

1. 选择“查资料”或输入 `@查资料`。
2. 补充**产品名称、资料类型、用途或版本**，例如：

   > @查资料 找一份产品 A 的私有化部署指南，用于实施前检查，优先当前有效版本。

3. 发送后等待检索完成，阅读“相关资料”卡片中的标题、类型、摘要和更新时间。
4. 选择适合的资料，按下表核对或使用。

[![查资料结果：资料标题、摘要、更新时间以及摘要、原文、下载和分发入口](/images/manuals/assistant-materials-v036.png)](/images/manuals/assistant-materials-v036.png)

| 卡片操作 | 用途与注意事项 |
| --- | --- |
| 查看摘要 | 打开来源详情，先核对资料内容和定位是否符合需求 |
| 打开飞书原文 | 查看完整原文；仍需具备相应飞书访问权限 |
| 下载 | 获取可下载的原文件；下载失败时按页面提示核对权限和文件状态 |
| 分发 | 选择可用渠道后，由你确认接收人并发送；不是点击即自动群发 |

手机支持系统分享时可唤起分享面板；电脑选择微信时会先下载文件并尝试打开微信，仍需手动发送。飞书分享取决于设备支持，钉钉当前未接入。分发不会生成无需授权即可访问的公开链接。

**没有结果时：** 缩小或调整产品名称、资料类型和版本条件；请管理员核对资料是否已审核、发布并完成索引，以及是否共享给当前账号。“知识库里存在文件”不等于该文件已可供助手检索。

**完成标准：** 找到并核对符合需求的资料，能打开来源或取得有权限下载的原文件。

### 3.4 做方案：从需求到可确认草稿

**适合：** 为客户需求起草解决方案、项目实施方案或汇报提纲。结果是需要核对的方案内容，不等同于直接生成可下载的 Word 或 PPT 文件。

#### 第一步：说明需求

选择“做方案 / 汇报”或输入 `@做方案`，说明客户或行业、业务目标、首期范围、部署约束和期望输出。已有需求文档时，可先上传附件并等待处理完成。

> @做方案 为一家制造企业制定内部知识检索试点方案。首期面向售前和实施团队，采用企业内网部署。请结合正式资料，给出目标、能力范围、实施步骤、验收方式和汇报提纲，标出缺少依据的部分。

企业正式资料用于核对能力和依据；你提供的需求、附件和假设应与正式证据分开理解。缺少信息时，助手可能先给出待补充的方案骨架。

#### 第二步：补充条件并继续

生成过程中可查看“执行过程”。出现“继续生成前，请确认方案条件”时，说明当前在等待你的补充，不是一直在后台生成。

[![方案条件确认：选择部署方式后提交并继续，也可标记暂不确定](/images/manuals/assistant-clarification-v036.png)](/images/manuals/assistant-clarification-v036.png)

- 按题目选择单项、多项或输入说明；选择“其他”时补充具体条件。
- 多个问题通过“下一项”逐项完成，最后点击“提交并继续”。
- 允许跳过的问题可选择“暂不确定”，明确保留未知条件；这不代表条件已经满足或获得证据支持。
- 运行已失效、无法提交条件时，保留原需求和已确认信息，重新发起方案生成。

#### 第三步：核对并保存草稿

[![方案草稿：执行摘要、需求清单、实施步骤、风险、证据与确认入口](/images/manuals/assistant-solution-v036.png)](/images/manuals/assistant-solution-v036.png)

重点核对以下内容（按本次结果实际返回的栏目为准）：

| 内容 | 核对重点 |
| --- | --- |
| 执行摘要、需求清单 | 是否准确表达客户目标、首期范围和约束 |
| 企业能力匹配 | 区分已有能力、可定制、研发储备和待确认，不能都视为现成能力 |
| 架构与方案章节 | 是否符合部署条件，实施步骤与验收方式是否可执行 |
| 依据、引用与可信度摘要 | 原文是否支持关键结论；覆盖比例不是交付成功率或效果保证 |
| 风险、冲突、待补充及审核节点 | 哪些需要补充证据，哪些需要业务或技术负责人确认 |

当前草稿卡片可编辑“执行摘要”，修改后点击“保存草稿”保存新版本。需要调整其他方案内容时，在会话中补充要求继续生成，并核对新结果。

#### 第四步：确认方案

| 草稿状态 | 下一步 |
| --- | --- |
| 生成中 | 查看执行阶段，等待结果或条件确认问题 |
| 待确认 | 核对需求、引用和能力边界后确认 |
| 需要复核 | 先按人工审核节点及风险提示复核，再决定是否确认 |
| 证据不足，暂不可确认 | 补充条件或正式资料，再继续生成；不能直接确认 |
| 已确认正式方案 | 查看已确认结果；需求变化时重新生成并核对版本 |

具备确认条件且完成核对后，点击“确认并生成正式方案”。**这里确认的是本次会话中的方案，不会自动将内容发布到企业公共知识库。** 若要供其他员工检索，仍需进入善达知枢的审核发布流程。

**完成标准：** 需求、依据和能力边界已核对，草稿已保存；需要定稿时，页面显示“已确认正式方案”。

### 3.5 如何理解回答状态

回答过程中可能显示理解问题、检索资料、核对原文、整理回答等阶段，这些是工作阶段，并非精确的完成百分比。

| 状态 | 含义 | 你可以做什么 |
| --- | --- | --- |
| 有正式资料支持 | 回答关联有效企业证据 | 核对引用是否支持关键结论 |
| 暂无足够可靠资料 | 当前没有足够可用证据 | 补充产品、版本或场景；请管理员补齐资料 |
| 资料存在冲突 | 不同正式来源在相同条件下存在不一致 | 分别检查来源，请业务负责人确认 |

“依据不足”不一定是系统故障，也可能是资料尚未发布、权限不足或条件不明确。不要把缺少证据的回答当作正式业务承诺。

## 4. 打开引用核对原文

点击回答中的引用编号，打开“来源详情”。

[![来源详情抽屉：资料名称、路径、定位、正文摘录和原文入口](/images/manuals/assistant-source-v036.png)](/images/manuals/assistant-source-v036.png)

1. **看标题和路径**：确认是你要查询的产品或制度资料。
2. **看定位**：核对页码、幻灯片、段落或工作表。Markdown 等内容按标题和段落定位，不一定有固定页码。
3. **看摘录和版本**：确认原文支持回答，且适用于当前产品版本、时间和业务条件。
4. 需要完整上下文时，点击原文入口；图片证据可在可用时查看预览。

**验收：** 可以指出回答的关键结论分别由哪条原文支持，而不仅是看到一个引用编号。

原文访问仍受权限和有效性检查限制。无法打开时，先确认登录身份，再请管理员核对来源、活动版本和权限。不要把无法访问的链接转发给无权限人员作为证据。

## 5. 上传附件辅助提问

在输入区使用“添加附件”，选择文件，等待附件处理完成后再发送问题。可直接说明“请结合附件中的需求，核对正式资料支持哪些能力”，避免只发文件而不说明任务。

- 一次最多添加 **5 个附件**，单个附件不超过 **100 MB**。
- 支持 PDF、Word、PPT、Excel、TXT、Markdown、CSV 和 PNG、JPG、WebP 等常见图片格式；以选择器实际允许的扩展名为准。
- 附件显示处理中时先等待；失败时查看提示，调整格式或大小后重新上传。
- 附件只用于会话上下文；要成为供全员检索的正式知识，需通过善达知枢的接入、审核和发布流程。

## 6. 管理会话

| 操作 | 使用场景 | 结果 |
| --- | --- | --- |
| 新建会话 | 开始新的主题 | 创建独立问答上下文 |
| 打开历史会话 | 查找之前的问题与答案 | 查看消息并继续可用会话 |
| 会话大纲 | 对话较长时定位问题 | 跳转到对应消息位置 |
| 归档会话 | 暂时结束一个主题 | 从常用会话中收起，保留历史 |
| 恢复会话 | 继续已归档的主题 | 恢复后再继续操作 |

归档不等于删除。历史回答反映当时的会话内容；关键业务决策前，应重新核对引用是否仍有效，必要时重新提问。

## 7. 反馈错误、过时或缺失的内容

有帮助的回答可以点赞。发现问题时，在对应回答下点踩，选择原因并补充说明。

[![回答反馈对话框，可选择内容错误、内容过时、资料缺失或引用错误等原因](/images/manuals/assistant-feedback-v036.png)](/images/manuals/assistant-feedback-v036.png)

| 原因 | 建议补充的信息 |
| --- | --- |
| 内容错误 | 哪一句不正确，正确依据是什么 |
| 内容过时 | 哪个版本或日期已变化 |
| 资料缺失 | 期望查到什么内容，可能对应哪份资料 |
| 引用错误 | 哪个编号不支持回答，或定位有什么问题 |
| 其他 | 具体操作、现象和期望结果 |

例如：“引用 [1] 适用于旧版产品，本次问题是新版，请核对版本适用范围。”比“回答不对”更便于处理。

**验收：** 页面显示反馈已提交。能定位到正式知识的反馈会形成治理待办，由管理员复核；提交反馈不会直接修改或下架企业知识。同一条消息的反馈提交后不能反复提交。

## 8. 常见问题

| 问题 | 处理建议 |
| --- | --- |
| 网页暂时无法加载 | 检查管理员提供的地址和网络，重新加载；持续异常时提供发生时间和页面提示 |
| 扫码后没有登录 | 核对手机是否完成确认、二维码是否过期；部署域名变化时由管理员核对回调配置 |
| 发送失败，请重试 | 先检查登录和网络，再使用重试；持续失败请管理员检查问答服务和模型连接 |
| 一直显示处理中 | 查看当前阶段与附件状态；记录时间和问题交给管理员，避免连续重复发送 |
| 想找现成方案，却开始起草新方案 | 使用 `@查资料` 并明确“找一份已有解决方案”；起草新内容才使用 `@做方案` |
| 方案停在条件确认 | 完成待确认问题后点“提交并继续”；暂时未知的条件按页面允许选择“暂不确定” |
| 方案无法确认 | 查看证据不足、冲突、人工复核提示；补充信息后继续生成 |
| 明明有资料却找不到 | 核对是否已发布、是否共享给当前账号、版本和来源是否有效，再细化问题 |
| 回答与原文不一致 | 打开引用核对，点踩并选择内容错误或引用错误 |
| 来源显示过期 / 无法打开 | 核对账号、权限与当前有效版本，联系知识管理员 |
| 新上传附件没有进入公共知识库 | 这是预期行为；附件不等于正式知识，需要另走审核发布流程 |

## 9. 知识更新何时生效

资料在飞书发生变化后，需要经过扫描、加工、审核与成功发布，才会成为助手可用的新知识。新版本仍待审核时，上一版有效知识可能继续提供服务；权限、下架和来源有效性仍然生效。

需要新增或更正公共知识时，把资料位置和修改原因交给知识管理员，由其在[善达知枢](./zhishu-manual)中处理，再回到助手验证答案与引用。
