# 术语与状态定义

本页统一管理界面、接口和运营沟通中使用的术语。遇到“来源一/来源二”“资料/知识”“分块/知识单元”等说法时，以本页定义为准。

## 内容对象

| 术语 | 定义 | 是否直接发布 |
| --- | --- | --- |
| 原始材料（Material） | 飞书 Wiki 节点、文档或上传的 PDF、Word、PPT、Excel、Markdown、图片等来源文件 | 否，始终保留为证据 |
| 来源材料（Source Item） | 知识源目录中的一个稳定资料条目，包含标题、路径、来源 URL 和当前活动版本 | 否 |
| 资料版本（Material Version） | 某个来源材料在一次扫描中发现的具体内容快照，由版本 ID 和内容 Hash 标识 | 否，需审核 |
| 来源片段（Source Segment） | 解析后带有页码、段落、幻灯片、工作表、单元格或图片区域定位的原文片段 | 否，作为知识单元组成部分 |
| 知识单元（Knowledge Unit） | 按章节、页面、幻灯片或工作表等结构归并、具有独立业务含义的审核对象 | 是，审核通过后可发布 |
| 内容块（Chunk） | 为向量检索和引用切分的细粒度文本或图片块 | 间接，随知识单元发布 |
| 正式知识（Formal Knowledge） | 已审核、已发布、来源有效且可被助手检索的知识单元及其索引 | 是 |

## 治理对象

| 术语 | 定义 |
| --- | --- |
| 审核包（Review Package） | 面向运营者的一份任务容器，通常对应一个资料版本，也可以由生命周期或用户反馈触发 |
| 审核项（Review Item） | 审核包中可独立作出决定的一项，当前主要是知识单元，也可代表跨文档关系 |
| 运营待办（Work Item） | 从审核包、来源变更、跨文档关系、加工失败、到期复核和用户反馈聚合出的工作项，不是第二套任务系统 |
| 跨文档关系（Cross-document Relation） | 两份材料或两个版本之间的重复、重叠、冲突、条件变体或证据不足关系 |
| 逻辑知识（Logical Knowledge） | 将同一事实的规范来源、别名来源或辅助来源组织起来的逻辑记录 |
| 处理记录（Processing Event） | 扫描、解析、审核、发布、下架、恢复、重试、跨文档裁决及治理元数据修改形成的追加式审计事件 |
| 通知投递记录（Notification Delivery） | 保存接收人、渠道、业务对象、幂等键、投递状态、重试和已读时间的通知记录 |

## 审核结果

| 界面文案 | 适用场景 | 结果 |
| --- | --- | --- |
| 纳入知识库 | 内容有效、来源可靠、需要被助手使用 | 当前知识单元进入发布队列；发布成功后成为正式知识 |
| 不纳入知识库 | 内容无业务价值、重复或不属于当前范围 | 知识单元完成判断，不进入正式检索；来源记录仍保留 |
| 退回飞书修改 | 事实错误、内容缺失、版本不明或解析问题 | 保留旧正式知识，等待来源修改后再次扫描 |
| 等待业务确认 | 仅凭当前证据无法安全裁决 | 任务保持打开，不会自动发布 |
| 保留来源一/来源二 | 重复关系中选择规范来源 | 另一侧可被标记为别名/重复来源，相关审核项按规则自动收口或继续待审 |
| 分别保留 | 两侧内容虽相似但适用范围不同 | 两侧都保留，并填写互斥的行业、产品、版本等范围 |
| 采用新版 | 冲突关系中确认候选版本替代当前正式版本 | 候选版本发布后，冲突的旧侧移出正式检索并保留审计记录 |
| 保留当前版本 | 冲突关系中继续使用当前正式版本 | 只有另一侧已经是正式版本时才可安全选择 |

## 状态定义

### 审核包

| 状态 | 含义 |
| --- | --- |
| `OPEN` | 仍有待处理知识单元或关系 |
| `WAITING_SOURCE_CHANGE` | 已退回来源，等待飞书产生新版本 |
| `WAITING_BUSINESS_CONFIRMATION` | 需要业务方补充事实或决定 |
| `COMPLETED` | 当前审核包内所有审核项均有明确结果 |
| `INVALIDATED` | 来源版本或关系已失效，不再继续处理 |

### 质量门禁

| 状态 | 含义 |
| --- | --- |
| `RECOMMENDED` | 评分 80–100 且没有硬性阻断，建议人工确认后发布 |
| `REVIEW` | 评分 60–79，需要重点人工复核 |
| `RETURN` | 评分低于 60，建议退回处理 |
| `BLOCKED` | 存在硬性阻断；分数不能抵消阻断项 |

硬性阻断包括：正文为空或解析失败、知识单元缺少可追溯位置、存在未解决跨文档冲突、来源失效或无法核验。

### 扫描与加工

| 状态/概念 | 含义 |
| --- | --- |
| 增量扫描 | 只处理新增或版本发生变化的材料；适合日常同步 |
| 全量扫描 | 重新核对配置范围内全部材料；适合首次接入、权限/目录调整或状态不一致时使用 |
| 解析 | 把文件转换成正文、版式信息、图片/OCR 和来源片段 |
| 索引 | 将已发布知识单元的内容块写入向量检索系统 |
| 发布 | 在事务中切换活动版本，成功后才删除或下线被替代的旧索引 |
| 失败重试 | 可恢复的资料加工失败按 1、5、15 分钟自动重试，最多 3 次；耗尽后进入人工待办 |

## 两个容易混淆的词

- **内容块 ≠ 知识单元**：内容块是检索切片，知识单元是审核和发布粒度；一个知识单元可以包含多个内容块。
- **来源变更 ≠ 正式知识变更**：扫描发现版本变化只会生成候选版本和审核任务。只有人工确认并发布后，助手才会使用新内容。
