# 知识加工

“知识加工”用于把来源材料转换为可审核、可发布的知识单元。进入菜单后默认打开“待审核”，便于审核人员直接开始工作。

## 页面区域

页面从上到下分为以下区域：

- **数据源概览**：显示素材总数、待审核、失败和来源失效数量。
- **功能页签**：在待审核、跨文档检查、正式知识、资料与扫描之间切换。
- **审核任务**：按材料列出待处理、等资料、已转交和已完成任务。
- **审核工作区**：展示原文版式、知识单元、跨文档证据和处理操作。

## 连接与扫描

### 检查连接

在扫描前确认飞书企业知识源可访问。连接失败时，优先检查租户凭证、知识库权限和网络状态。

### 增量扫描

日常使用优先选择增量扫描。系统会遍历已配置的知识空间来确认目录和版本状态，但只为新增或发生版本变化的材料创建新版本并进入解析、审核流程；没有变化的材料不会重复创建审核任务，整体处理更快。首次使用前必须先完成一次成功的全量扫描。

### 全量扫描

以下情况适合执行全量扫描：

- 第一次接入知识源
- 调整了目录或权限范围
- 历史扫描不完整
- 需要重新建立全部材料状态

全量扫描会重新核对知识空间内的全部资料，并同步发现失效、移动或权限变化的来源，耗时和接口调用量更高。全量扫描不会直接把所有材料发布为正式知识，扫描结果仍需要经过审核。

## 待审核

待审核页按原始材料组织任务，并显示已处理、待处理和已纳入的知识单元数量。

选择任务后，可以在工作区中：

1. 查看原文版式和当前页。
2. 在同一页选择可定位的内容块。
3. 查看系统归并出的当前知识单元。
4. 对比跨文档证据或版本变化。
5. 处理当前知识单元，或对整篇材料执行批量操作。

## 跨文档检查

跨文档检查用于识别不同材料中可能重复或高度相似的知识。系统同时提供来源、对应页和文字证据，审核人员应以实际高亮内容为准。

如果只有相似来源、没有可核对的重叠正文，该结果不能作为重复依据，应重新运行检查或按当前材料独立审核。

典型场景是多份产品介绍中都包含“公司简介”：

- 首次出现且内容有效时，选择一份作为正式知识来源。
- 其他相同内容选择“不纳入知识库”。
- 后续材料出现更新版本时，再比较差异并更新对应知识单元。

## 正式知识

正式知识只显示已经审核并成功发布的内容。提交审核后未出现在此处时，可依次检查：

1. 知识单元是否选择“纳入知识库”。
2. 整篇任务是否仍有未处理单元。
3. 发布任务是否失败或仍在处理中。
4. 当前账号是否拥有对应知识库的查看权限。

## 资料与扫描

此页用于查看来源材料、扫描批次和失败信息。系统会复用已加载的统计与列表数据，只有手动刷新、执行扫描或数据发生变化时才重新请求。

## 常见状态

| 状态 | 含义 | 建议处理 |
| --- | --- | --- |
| 待审核 | 仍有知识单元需要判断 | 进入任务继续处理 |
| 等资料 | 当前材料不足以完成判断 | 补充材料后继续 |
| 已转交 | 已交由其他审核人员处理 | 等待接收人完成 |
| 已完成 | 所有知识单元已有明确结果 | 到正式知识核对发布结果 |
| 失败 | 解析、证据检查或发布过程失败 | 查看失败原因并重试 |
