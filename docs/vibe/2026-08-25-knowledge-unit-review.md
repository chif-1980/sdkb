# 知识单元级审核与发布

## 目标

在现有飞书知识加工、来源片段、审核包和正式发布链路上增加“知识单元”层，使审核人员可以局部纳入、局部排除或退回修改，同时让正常资料仍可通过批量采用系统建议快速完成。

## 核心关系

```text
原始材料版本
  -> 来源片段（解析、定位、检索的技术颗粒度）
  -> 知识单元候选（审核和变更的业务颗粒度）
  -> 审核项（人工裁决）
  -> 正式知识与可重建索引
```

- 一个知识单元由一个或多个来源片段组成。
- 来源片段必须且只归入一个当前版本知识单元，避免局部发布状态互相覆盖。
- 正式逻辑知识可以关联多份材料中的多个知识单元，不重复发布相同事实。
- 原始材料保留完整上下文、版本、权限和审计信息，不直接等同于一条正式知识。

## 本轮范围

1. 增加版本化知识单元候选及来源片段映射。
2. 按章节、页面、幻灯片、工作表和结构化内容自动归并知识单元。
3. 为知识单元生成系统建议、置信度、变化类型和是否需要人工关注。
4. 将未裁决的材料级审核项转换为知识单元级审核项。
5. 支持批量采用低风险建议和逐项修改例外决定。
6. 局部决定直接更新知识单元及其来源片段的发布状态。
7. 整份材料只有在全部知识单元完成处理后才结束审核；至少一个单元纳入时发布仅包含已纳入片段的索引。
8. 新版本自动识别未变化、修改、新增和疑似删除的知识单元；未变化单元沿用已有决定。

## 不在本轮范围

- AI自由生成或改写知识正文。
- 任意字符范围的拆分编辑器。
- 单个知识单元独立转交负责人。
- 自动归档从新材料中消失的正式知识。
- 音视频知识单元处理。
- Word、Excel、PDF和图片查看器的完整新版式还原。

## 验收标准

- 一份包含多个章节或PPT页面的材料能生成多个有完整含义的知识单元。
- 审核页面默认只显示需要人工处理的单元，并显示全部单元处理摘要。
- 审核人可一键采用所有低风险系统建议，无需逐片段点击。
- 同一材料可以同时存在已纳入、不纳入、引用已有知识和等待修改的单元。
- 仅已纳入单元进入发布索引；不纳入、待修改和未决冲突不会被知识助手召回。
- 新版本中内容完全不变的单元不会重新要求人工审核。
- 所有决定保留审核人、时间、来源片段和原始定位信息。
- 旧材料级审核接口仍可处理尚未转换或没有有效来源片段的资料。

## 重复来源自动收口（2026-09-03）

- 选择“保留来源一”或“保留来源二”后，只自动结束另一来源中全部来源片段均已判定重复的知识单元。
- 含独有片段或仍关联其他未解决跨文档关系的知识单元继续待审；所选规范来源仍需正常审批。
- 另一来源没有剩余待审知识单元时，审核包自动完成并退出待审核队列；候选版本记录为无需再次审批。
- “分别保留”只结束当前跨文档关系，不自动处理两边的知识单元。

- [x] 前端展示自动处理数量、剩余待审数量、重复来源完成结果和无需再次审批提示。
