# 企业知识助手双回答模式

## 目标

企业知识助手在同一个问答入口提供两种回答模式：

- 简洁模式：保留现有一次混合检索、正式知识校验和流式生成流程。
- 详细模式：使用 LangGraph 进行有限次数的多步调查，再由现有严格引用生成器输出答案。

## 边界

- 请求只增加 `mode: CONCISE | DETAILED`，默认 `CONCISE`，不改变旧调用方行为。
- 详细模式不调用 Yuxi 默认知识库工具，只开放产品专用的检索、打开原文和文档内定位工具。
- 每次工具调用都重新校验当前用户权限、资料发布状态、当前有效版本和可信飞书来源地址。
- 未审核、未发布、已失效、存在未决冲突或当前用户无权限的资料不能进入调查结果、最终答案或引用。
- 最终答案继续使用现有结构化状态、严格证据编号和飞书来源引用，不采用 Agent 自由生成的引用。
- 本次不增加会话级模式字段；输入区当前选择只作用于本次提问。

## 交互

- 输入区增加紧凑的“简洁 / 详细”分段控件。
- 简洁模式提示“快速直接回答”，详细模式提示“多步查证后回答”。
- 发送期间禁止切换，等待状态沿用“理解问题、检索资料、核对依据、组织答案”四阶段链条。

## 验收清单

- [x] 省略 `mode` 时仍执行原有简洁流程。
- [x] 详细模式通过 LangGraph 多次调用受控知识工具，并在限定次数内停止。
- [x] 两种模式均支持非流式接口、SSE 流式输出和现有消息持久化。
- [x] 详细模式每次工具调用和最终生成前都重新校验知识范围。
- [x] 未发布、无权限、失效或有未决冲突的资料不会出现在答案与引用中。
- [x] 前端正确发送当前模式，发送期间禁用切换，移动端不溢出。
- [x] 相关后端测试、前端测试、类型检查和构建通过。
