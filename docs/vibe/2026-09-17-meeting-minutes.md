# 会议纪要首版

目标：在企业助手现有对话和后台 worker 中，将公开分享链接、文字或文档整理为可追溯、可编辑、可导出的会议纪要。保留 MEETING_ANALYSIS 标识和 @分析会议 别名。

实现：LangGraph 编排读取、分段提炼、纪要生成、原文核对、授权知识检索和业务分析。LLM 分析语义；代码校验来源完整性、网络边界、引用和访问权限。听悟与 BuddyNote 使用直接读取路径；其他公开平台由服务器 Chromium 与 LLM 自动尝试选择已观察到的转写、展开和翻页控件，不要求逐平台扩展代码，不保证所有平台均可读取。
