# 会议纪要跟进首版

## 目标

让会议纪要结果可以直接推动后续工作，同时把知识维护决策留在善达知枢。

## 已实现范围

- 上传会议资料的会话所有者自动成为会议跟进负责人。
- 只展示明确行动项；负责人、期限缺失时分别显示“待分配”“期限待定”。
- 负责人只能从当前登录用户所属飞书企业的已授权成员中选择，后端再次校验租户边界。
- 任务负责人、期限和状态沿用会议版本保存，发生版本冲突时拒绝覆盖。
- 知识更新建议和行动项分开显示，建议状态为“待知识维护人员处理”，助手端没有直接纳入知识库操作。
- 旧会议结果没有跟进投影时仍可正常查看和导出；新生成的会议结果携带跟进投影。

## 验收清单

- [x] 会议结果中行动项与知识建议分开持久化。
- [x] 同租户目录选人和越权拒绝。
- [x] 缺失负责人和期限不被模型补猜。
- [x] 会议正文编辑与跟进保存使用同一版本保护。
- [x] 前后端单元测试覆盖投影生成、跟进展示与保存。

## 首版边界

首版只在当前会议和当前应用内跟踪，不发送飞书消息、不创建飞书任务、不自动发布知识，也不允许被分配人因此获得会议全文访问权。
