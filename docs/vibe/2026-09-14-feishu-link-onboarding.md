# 飞书知识数据源接入优化

目标：使用飞书知识库页面链接接入，衔接已有授权、连接检查、扫描和审核发布。

- 输入链接，由服务端解析节点，默认同步页面及下级，可选择整个空间。
- 不输入 Token、应用密钥或知识库 ID；默认自动创建同名知识库，按需展开选择已有知识库，唯一可用项自动选择。
- 自动创建复用平台 `embed_model`，不可用时明确提示配置，不擅自改选模型。创建待授权空库，授权检查成功后使用链接页面标题命名；已有同名库时追加来源短编号，不复用或覆盖同名库。
- 新库默认仅创建者可见，可在现有知识库设置中共享。保存来源失败清理本次新库，授权失败可在原来源重试，命名完成后不会随重新授权覆盖用户修改的库名。
- 保存后复用管理员扫码授权，授权回跳恢复对应数据源，自动检查连接。
- 首次成功全量扫描后开放增量扫描；保留原有扫描进度、资料加工和审核发布。
- 顶部始终可管理、切换数据源及重新授权；扫描和授权进行中禁止切换。
- 重新授权保留扫描及审核历史；更换链接或范围通过添加新数据源，避免历史基线混用。
- 当前支持飞书，后续来源通过独立接入适配扩展，本次不展示不可用的占位入口。

- [x] 现有飞书扫描与审核流水线回归测试通过。

- [x] 记录真实飞书授权验证需要的外部条件，不将模拟测试当作真实接入成功。

验证记录：前端 46 项通过；后端相关回归 54 项通过、1 项真实飞书联网测试跳过，包含 4 项离线端到端测试；补充来源摘要 4 项通过、最终链接校验 16 项通过。最终链接测试进程在测试完成后的垃圾回收阶段被中断，断言均通过。前后端 Lint 和差异空白检查通过。

部署后验证：后端重启完成，健康检查返回 HTTP 200；浏览器刷新知识加工页面正常，顶部数据源管理可打开新表单，正式知识库空状态、创建入口及保存限制均已确认。

当前真实环境无可写入的正式知识库，未创建示例来源或自动选择模型。扫码回调配置仍为 `192.168.10.193:5173`，浏览器回调为 `127.0.0.1:5173`，当前管理页面为 `172.16.22.14:5173`。真实扫码前需要核对飞书开放平台登记的回调地址、手机可访问的服务地址，以及一个管理员可访问的飞书知识库页面链接。未声称真实授权及联网扫描已验证。
