# 项目简介

善达知枢是善达信息面向企业知识治理和智能问答场景建设的平台。系统以原始材料、知识单元和内容块三个层级管理知识，通过人工审核确保正式知识可追溯、可更新、可控制。

## 核心能力

### 企业资料接入

连接飞书企业知识源，并支持 Word、Excel、PDF、PPT、图片等常见材料。扫描过程记录材料版本、来源位置和处理状态。

### 知识加工与审核

系统解析原始版式，归并知识单元，并通过跨文档检查发现重复或更新内容。审核人员可以处理单个知识单元，也可以在整篇材料内容一致时执行批量操作。

### 正式知识管理

只有审核确认纳入的知识单元才会发布。系统保留来源、版本、处理结果和内容块定位，便于后续局部更新或整篇替换。

### 可信知识问答

知识助手检索已经发布的正式知识，提供简洁和详细两种回答模式，并展示可核对的引用来源。

## 技术基础

| 层级 | 主要技术 | 用途 |
| --- | --- | --- |
| 前端 | Vue 3、Vite、Ant Design Vue | 管理端与审核工作区 |
| 后端 | FastAPI、LangGraph、异步 Worker | 接口、智能体与后台任务 |
| 数据 | PostgreSQL、Redis、MinIO | 状态、任务和原始文件 |
| 检索 | Milvus | 正式知识向量检索 |
| 文档理解 | Office/PDF 解析、OCR | 多格式版式还原与文字定位 |
| 部署 | Docker Compose | 私有化部署与服务编排 |

## 开源基础

善达知枢基于 [Yuxi](https://github.com/xerrors/Yuxi) 开源项目持续开发，并保留原项目的 MIT License 约定。企业知识加工、知识单元审核、跨文档证据和独立知识助手等能力在此基础上进行了面向业务场景的完善。
